# Roman Expression Calculator

A command-line calculator that evaluates mathematical expressions written with Roman numerals.

## Features

- Supports standard Roman numerals:
  - I = 1
  - V = 5
  - X = 10
  - L = 50
  - C = 100
  - D = 500
  - M = 1000

- Supports arithmetic operations:
  - `+` Addition
  - `-` Subtraction
  - `*` Multiplication
  - `/` Division
  - `^` Power

- Supports grouping with parentheses:
  - `( )`

- Supports Roman decimal notation using square brackets:
  - `[V]` = 0.05
  - `[L]` = 0.50
  - `[LXXV]` = 0.75

- Expression validation with detailed error messages.
